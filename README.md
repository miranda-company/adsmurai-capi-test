# Adsmurai CApi Test
This repo contains the CAPI test for Adsmurai.

The goal of this test is to create a tool that pulls data from an CSV file (provided by Adsmurai), format the data to meet META requirements and push the data into Meta obtaining a 200 response code.

## About the test

**Test instructions**
https://docs.google.com/document/d/1-8kk8EEcaxqnCitjWEcZfr04H2e1CfqYTAKc-S6WEqU/edit?tab=t.0

**Test objectives**
The goal is to develop a tool to read the offline conversions from this file (CSV), format them to meet Meta requirements, and upload them to their Meta pixel. 

So, we expect from this test a tool that:
1) Reads the file from an URL
2) Formats the data and hashes the required fields from the file
3) Uploads it to Meta, obtaining a 200 response from it

The tool should be developed using Nodejs and any library, but it should be able to run on a server.
In order for us to review the tool, please send us a repository link from any repository hosting service (like GitHub) that contains all the necessary files and instructions to make the tool work on our local machines.
